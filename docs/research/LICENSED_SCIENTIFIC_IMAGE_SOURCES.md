## Integration requirements

1. Biology reviewer validates identity and labelled anatomical structures against prescribed syllabus before use. A specimen photograph is a reference, **not** a replacement for a labelled anatomy diagram.
2. Download the unchanged licensed source from the linked Commons file page, preserve the original if feasible, convert to PNG with a recorded derivative change statement, and capture SHA-256 and original width/height.
3. Map only to the matching topic, section and diagram ID in the 64-slot registry. The three `SUPPLEMENT_ONLY` sources have no occupied diagram slot.
4. Provide an image-credits page in both languages; include source, creator, licence, link and modification details next to the image. Proper names and Latin binomials may remain unchanged.
5. Check licensing and ShareAlike before distributing an APK containing modified versions. Keep images with uncertain licensing separate.
6. Run emulator screenshots at English 100% and Tamil 200%, pinch zoom and Android physical-device QA. An image listed here but absent from APK assets must never be shown as available.
