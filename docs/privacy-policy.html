Privacy Policy — Chordata Atlas

Last updated: 12 November 2026

This policy applies to Chordata Atlas, an offline learning application from the Department of Zoology, Government Arts & Science College, Nagercoil, India. No user account or sign-in is provided.

Information stored locally

Completed lessons, bookmarks, quiz scores, reading language and text-size preferences are saved in private app storage on the user's device. Unsubmitted quiz choices may remain temporarily in the current app session. The app does not request personal details.

Collection, sharing and external services

Chordata Atlas does not request Internet access, upload user information, run ads, or integrate third-party analytics or user-tracking services. Learner progress and preferences are not transmitted to the developer or third parties. Course materials, figures and credits are bundled inside the application for offline use.

Security and retention

Local settings are stored in the app's private Android storage. Android application backup is disabled. The app does not maintain server-side copies of learning records. Local records remain on the device until the user chooses the in-app Erase all learning data control, clears app storage or uninstalls the app.

Optional manual backup and restoration

The app can export completed lessons, bookmarks, quiz scores, reading language and text-size preferences to a readable, unencrypted JSON file using Android's system file picker. You choose where to save it. The app does not transmit a backup to its developer or upload it automatically. Files saved to external storage or a cloud provider selected by the user may be accessible to that provider and other apps according to the user's settings. Do not share a backup file if you wish to keep learning records private.

Importing a selected backup file requires explicit confirmation and replaces existing local learning progress and preferences. The app checks the backup schema before modifying saved records. Erasing learning data or uninstalling the app does not erase any backup files you previously saved outside the app; delete those separately using the relevant file provider.

Deleting local data

To erase local learning records and preferences, open the in-app Privacy policy, select Erase all learning data and confirm. Alternatively, uninstall Chordata Atlas or use Android Settings > Apps > Chordata Atlas > Storage > Clear storage (the precise wording depends on the device). There is no online account to delete.

Privacy enquiries

For questions regarding this application's privacy practices, please use the developer contact details given on its Google Play store listing. The store publisher must confirm an active contact channel before submitting the application for publication.

Changes

This privacy policy must be reviewed and updated if future application releases introduce new data handling, network services, advertising or analytics.
