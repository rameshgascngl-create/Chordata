# CHORDATA launcher identity

The owner approved the ivory bird / mammal negative-space / golden fish emblem
on 11 November 2026. The source PNG is AI-generated with OpenAI image generation
for this project, not a third-party illustration or an anatomical diagram.

- Source: `chordata_launcher_approved.png` (unchanged approved artwork).
- Store export: `chordata_store_icon_512.png` (512 × 512, opaque).
- Android 24–25: density-specific normal and circular PNG mipmaps.
- Android 26+: adaptive icon using the approved art with 6 dp inset.
- Android 33+: monochrome alpha silhouette for themed launchers.

Only resizing, launcher mask preparation and monochrome conversion were applied.
The launcher manifest refers to mipmaps. Course figures and their attribution
remain unchanged. The previous drawable is retained for source history only.
